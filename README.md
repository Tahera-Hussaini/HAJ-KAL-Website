## سفارش
دکمه سفارش هر محصول یک پیام آماده واتساپ ایجاد می‌کند و نام/کد محصول را همراه خود دارد.
قیمت، سایز، رنگ و موجودی عمداً اختراع نشده‌اند و هنگام سفارش از طریق واتساپ پرسیده می‌شوند.

## انتشار در Netlify
1. فایل ZIP را باز کنید.
2. پوشه پروژه را در GitHub قرار دهید، یا محتوای آن را در Netlify Drop بارگذاری کنید.
3. چون پروژه استاتیک است، Build Command لازم نیست.
4. Publish directory همان ریشه پروژه است.
5. پس از انتشار، Netlify یک لینک عمومی برای فروشگاه می‌دهد.

## نکته
برای تغییر نام یا اطلاعات هر محصول، فایل `index.html` را ویرایش کنید. برای اضافه/حذف محصول، کارت محصول را کپی یا حذف کنید.
